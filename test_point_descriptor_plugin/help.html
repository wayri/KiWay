KiWay Test Point Descriptor Extractor

Annotated interface walkthrough

The numbered cues below match the visible workflow in the plugin. A preview is the review evidence; committing or exporting is the final step.

Extracts test-point descriptors and produces CSV, Markdown, and HTML documentation for integration and test teams.

Cross-selection: double-click a test-point row or use Select on PCB to select its TP footprint before approving the descriptor.

Workflow

  1. Set the custom descriptor field, typically TP_Descriptor.
  2. Enter system board order, e.g. DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO.
  3. Click Extract, inspect source/destination and type fields, and cross-select suspect TPs.
  4. Export the controlled CSV, Markdown, or HTML report.
