KiWay Test Point Descriptor Extractor

Extracts test-point descriptors and generates controlled CSV, Markdown, and HTML documentation.

Use

  1. Open the PCB and launch the plugin.
  2. Enter the custom field containing the descriptor, such as TP_Descriptor.
  3. Enter board order, for example DEMO_CTRL,DEMO_SENSOR,DEMO_POWER,DEMO_IO.
  4. Click Extract, review the table, and export the required document.

Example

The label DEMO_CTRL_DEMO_SENSOR_SIGNAL_SPI1_CLK_1_TD produces source board DEMO_CTRL, destination board DEMO_SENSOR, signal SPI1_CLK_1, and type Telemetry Digital.

Common issues

  • Descriptor blank: verify the field name or use one of the fallbacks Descriptor, Function, or Description.
  • Board endpoints blank: provide board names in the exact comma-separated order used by the labels.
  • No rows: use TP references or values containing TestPoint.
